# JJZero Audio 0.3.2

> Studio 후처리와 결과물 내보내기를 실제 제작 단계에 맞게 확장한 0.3 유지보수 릴리스입니다.

0.3.2는 작업곡과 재생 상태의 일관성을 유지하면서 Studio에 영상·이미지와 음성 효과를 추가하고, 결과물을 용도에 맞는 형식으로 바로 내보낼 수 있게 합니다. 기존 라이브러리, 모델, 작업곡과 Studio 세션은 그대로 유지됩니다.

## Studio 음성 효과

- 라디오 필터, 링 모듈레이터, 비트크러셔, 디스토션을 타임라인 클립에 드래그해 적용할 수 있습니다.
- 애니매트로닉, 무전기, 고장 난 로봇 프리셋으로 여러 효과를 한 번에 구성할 수 있습니다.
- 각 효과는 프리셋으로 시작한 뒤 속성 패널에서 세부 값을 조절할 수 있습니다.
- 재생 중 설정 변경은 실시간 미리듣기에 반영되며, 내보낼 때도 같은 효과 체인을 사용합니다.

## 원본 음량 추종

- Level Match 효과는 변환 보컬의 음색은 유지하면서 원본 보컬의 구간별 음량 변화를 따라가게 합니다.
- 추종 강도, 반응 속도, 최대 보정량과 무음 기준을 조절할 수 있습니다.
- 원본 참조가 없거나 무음인 구간은 안전하게 건너뜁니다.

## 오디오 및 영상 내보내기

- 오디오와 영상 내보내기를 독립된 화면으로 나누고, 선택한 설정으로 즉시 내보내도록 정리했습니다.
- 마스터 WAV, 무손실 FLAC, 공유용 MP3, Discord 10MB, 사용자 설정 오디오 프리셋을 제공합니다.
- Discord 프리셋은 곡 길이에 맞는 Opus 비트레이트를 계산해 가능한 범위에서 10MB 이내의 가장 높은 음질을 선택합니다.
- 영상은 YouTube 1080p, 고품질, 소용량 720p와 사용자 설정 프리셋을 제공합니다.
- 내보낸 오디오는 목록에서 바로 재생하고 이름을 바꾸거나 폴더를 열 수 있습니다.

## Studio 미디어와 편집 경험

- 이미지와 영상을 사운드 풀과 같은 방식으로 Studio에 배치하고 타임라인에서 길이와 위치를 조절할 수 있습니다.
- 재생 헤드와 클립은 드래그하는 동안 포인터를 따라가며 놓는 순간 한 번의 편집 기록으로 확정됩니다.
- 사운드 풀은 같은 작업곡으로 다시 들어올 때 기존 카드를 재사용해 Studio 진입 지연과 검은 화면 깜박임을 줄였습니다.
- 페이지가 만들어지는 동안 내부 위젯이 별도 창처럼 순간 표시되던 문제를 수정했습니다.

## RVC 및 시스템 진단

- RVC 변환에 인덱스 비율, 필터 반경, 원본 음량 혼합과 자음 보호 설정을 추가했습니다.
- 시스템 진단에서 음성 변환 장치와 모델 학습 장치를 구분해 표시합니다.
- AMD DirectML 환경은 GPU 음성 변환과 CPU 모델 학습을 별도 상태로 안내합니다.
- 변환 및 공유 실패 로그에 실제 적용 장치와 주요 설정을 더 남겨 이후 진단 정확도를 높였습니다.

## 업데이트 전 확인

- 기존 곡, 모델, Studio 세션, 출력 파일과 사용자가 선택한 저장 위치는 업데이트 후에도 유지됩니다.
- 이번 버전은 0.3.1과 같은 AI 런타임을 사용하므로 정상 구성된 환경에서는 대용량 런타임을 다시 받을 필요가 없습니다.
- 정식 설치 파일과 자동 업데이트 구성요소는 [GitHub Releases](https://github.com/groun519/JJZ-Audio/releases)에서 제공합니다.
