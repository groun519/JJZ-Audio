# JJZero Audio 0.3.7

> 단일 GPU 환경에서 RVC 학습이 첫 배치 전에 멈출 수 있던 문제를 수정한 학습 안정화 핫픽스입니다.

0.3.7은 단일 GPU 학습을 시작한 뒤 작업자는 실행된 것처럼 보이지만 첫 배치가 전달되지 않아 진행이 멈출 수 있던 문제를 수정합니다. 특히 AMD·ROCm 환경을 위해 적용한 단일 장치 학습 호환 코드가 DataLoader 작업 프로세스까지 대체하지 않도록 실행 범위를 분리했습니다. 기존 곡, 모델, 학습 재료, 체크포인트와 출력 파일은 그대로 유지됩니다.

## 단일 GPU 학습 복구

- 단일 장치 학습에서 RVC 랭크 프로세스만 현재 학습 프로세스 안에서 실행합니다.
- 학습 재료를 읽는 DataLoader 작업자는 기존의 실제 멀티프로세스 구현을 유지합니다.
- 백그라운드 작업자에는 콘솔 창을 띄우지 않는 번들 `pythonw` 실행 경로를 계속 사용합니다.
- 첫 배치가 도착하지 않아 학습 진행률이 멈춰 보이던 원인을 제거했습니다.
- 병렬 작업자가 실패할 때 안전한 단일 작업자 설정으로 재시도하는 기존 복구 경로는 그대로 유지됩니다.

## 검증

- 번들 RVC Python 런타임에서 DataLoader 작업자 2개를 실제로 실행했습니다.
- 작업자 초기화 진단과 첫 배치 준비 진단이 모두 기록되는지 확인했습니다.
- 단일 장치 DDP 대체, RVC 자식 프로세스 import, 체크포인트 저장 회귀 테스트를 함께 수행했습니다.

## 업데이트 안내

- 0.3.6과 같은 AI 런타임 구성요소를 사용하므로 정상 구성된 환경에서는 대용량 런타임을 다시 받을 필요가 없습니다.
- 학습이 첫 배치 전에 멈췄던 사용자는 0.3.7로 업데이트한 뒤 동일한 학습 작업을 다시 시작하면 됩니다.
