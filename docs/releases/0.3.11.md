# JJZero Audio 0.3.11

> 라이브러리 정리와 진단 접근성을 강화하고, 스튜디오·업데이트·제거 과정에서 사용자 작업을 더 안전하게 지키는 안정화 업데이트입니다.

0.3.11은 라이브러리 그룹, 활동 기록과 환경 관리, 스튜디오 반응성, 업데이트 복구와 안전한 제거를 중심으로 개선합니다. 기존 곡, 모델, 학습 재료, 스튜디오 프로젝트와 출력 파일은 그대로 유지됩니다.

![작업 기록과 환경 관리](https://raw.githubusercontent.com/groun519/JJZ-Audio/v0.3.11/docs/assets/releases/0.3.11/environment-management.png)

## 라이브러리 그룹

- 라이브러리 곡을 그룹과 하위 그룹으로 정리할 수 있습니다.
- 여러 곡을 선택해 한 번에 다른 그룹으로 이동할 수 있습니다.
- 가져오는 곡을 저장할 그룹을 미리 선택할 수 있습니다.
- 그룹을 삭제해도 곡과 실제 파일은 삭제되지 않고 `미분류`로 이동합니다.
- 선택한 그룹과 펼친 항목, 그룹 패널 너비를 다음 실행에도 유지합니다.

## 활동 센터와 진단

- 실행 중인 작업과 최근 작업을 활동 센터에서 함께 확인할 수 있습니다.
- 완료되거나 실패한 작업의 기록, 로그와 실행 환경을 별도 진단 창에서 확인할 수 있습니다.
- 앱을 다시 실행한 뒤에도 저장된 작업 기록을 검색하고 상태별로 확인할 수 있습니다.
- 지원 요청에 필요한 앱 로그와 시스템 정보를 진단 ZIP으로 만들 수 있습니다.
- 진단 ZIP에는 사용자 음원, 모델과 인증 정보가 포함되지 않습니다.
- 전체 하드웨어 진단은 사용자가 요청할 때만 다시 실행합니다.

## 스튜디오 재생과 편집

- 스튜디오 진입 후 재생 준비를 백그라운드에서 시작해 첫 재생의 대기 시간을 줄였습니다.
- 재생 중 효과 설정을 바꿀 때 현재 위치를 유지하면서 결과를 자연스럽게 갱신합니다.
- 긴 프로젝트의 영상과 파형은 실제로 필요할 때 불러와 화면 전환과 편집 반응을 개선했습니다.
- 클립 효과와 미디어 속성을 우측 검사기에서 더 명확하게 확인하고 조정할 수 있습니다.
- 실시간 재생과 내보내기의 음량 상한과 효과 처리 결과를 일관되게 맞췄습니다.

## 저장과 학습 복구

- 스튜디오 자동 저장을 UI 작업과 분리하고, 저장 실패 시 대기 중인 변경을 보존해 다시 시도합니다.
- 로그 파일 교체 중에도 현재 앱 로그를 계속 기록할 수 있도록 안정성을 보강했습니다.
- RVC 학습이 끝난 뒤 모델 등록 단계에서 문제가 생겨도 검증된 결과를 복구할 수 있습니다.
- 불완전한 체크포인트는 완성된 모델로 잘못 등록하지 않습니다.

## 업데이트 안내

- RVC 체크포인트를 제한된 방식으로 읽도록 AI Runtime이 버전 5로 업데이트됩니다.
- CUDA 12.8, DirectML, Windows ROCm 가속 프로필 자체는 변경되지 않아 검증된 기존 프로필을 재사용합니다.
- 설치 프로그램은 기존 저장소 위치와 사용자 자료를 유지하며, 변경되거나 누락된 Runtime 구성만 받습니다.
- 학습이나 변환 작업이 실행 중이라면 종료한 뒤 업데이트하는 것을 권장합니다.
