# JJZero Audio 0.3.6

> 앱 내 업데이트 설치, 외부 RVC 모델 가져오기와 AMD DirectML 변환을 복구한 긴급 안정화 업데이트입니다.

0.3.6은 업데이트 설치를 누르면 JJZero Audio만 종료되고 이전 버전이 다시 실행되던 문제를 수정합니다. 일반 RVC 배포 ZIP을 바로 가져올 수 있게 했고, AMD DirectML 환경의 RMVPE 검사 경로와 모듈 탐색도 보강했습니다. 기존 곡, 모델, 학습 재료, Studio 세션과 출력 파일은 그대로 유지됩니다.

## 앱 내 업데이트 복구

- 설치 프로그램을 시작하기 전에 앱이 보유한 Windows 실행 잠금을 안전하게 해제합니다.
- 설치 프로그램 실행이 실패하면 실행 잠금을 다시 생성해 현재 앱을 정상적으로 계속 사용할 수 있습니다.
- 0.3.4와 0.3.5 앱이 사용하던 내부 `/RUN` 업데이트 요청도 새 설치 프로그램이 수용합니다.
- 수동 설치와 제거는 JJZero Audio가 실행 중일 때 계속 차단해 파일 손상을 방지합니다.
- 실제 앱 실행 잠금이 유지된 상태에서 내부 업데이트 설치가 완료되는 회귀 검증을 추가했습니다.

## 일반 RVC ZIP 가져오기

- JJZero Audio 전용 매니페스트가 없는 일반 RVC ZIP에서도 추론용 `.pth`와 선택적 `.index`를 가져올 수 있습니다.
- 학습 체크포인트만 있는 ZIP은 추론 모델로 잘못 등록하지 않습니다.
- 중복 파일명, 상위 경로 이동과 비정상 압축 경로는 가져오기 전에 차단합니다.
- JJZero Audio 전용 패키지는 기존 매니페스트·체크섬 검증을 그대로 적용합니다.

## AMD DirectML 안정화

- RMVPE 검사 프로세스가 준비된 검사 폴더에서 실행되면서도 RVC 모듈을 정상적으로 찾게 했습니다.
- RVC 루트를 하위 프로세스의 `PYTHONPATH` 첫 항목으로 전달합니다.
- AMD 변환에 필요한 RMVPE 스크립트와 라이브러리 파일이 없으면 프로필을 통과시키지 않고 복구 가능한 오류로 안내합니다.
- 공유용 진단 보고서에서 잘못된 모델 패키지와 실행환경 오류를 더 정확히 구분합니다.

## 업데이트 전 확인

- 0.3.5에서 업데이트 버튼을 눌렀을 때 앱만 종료됐다면 JJZero Audio를 다시 열어 0.3.6 업데이트를 받으면 됩니다.
- 앱에서 업데이트가 다시 표시되지 않으면 [GitHub Releases](https://github.com/groun519/JJZ-Audio/releases/latest)의 `JJZero-Audio-0.3.6-Setup.exe`를 한 번 직접 실행할 수 있습니다.
- 0.3.5와 같은 AI 런타임 구성요소를 사용하므로 정상 구성된 환경에서는 대용량 런타임을 다시 받을 필요가 없습니다.
