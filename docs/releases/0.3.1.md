# JJZero Audio 0.3.1

> 업데이트 안정성과 스튜디오의 실시간 리버브 작업을 다듬은 0.3 유지보수 릴리스입니다.

0.3.1은 기존 라이브러리와 모델을 유지한 채 0.2.x에서 0.3.x로 넘어가는 업데이트 경로를 보강하고, 스튜디오에서 클립에 리버브를 직접 적용해 재생과 내보내기 결과를 바로 확인할 수 있게 합니다.

## 스튜디오 클립 리버브

- 사운드 풀 아래의 FX 영역에서 리버브를 원하는 타임라인 클립에 드래그해 적용할 수 있습니다.
- 잘라낸 클립마다 독립적인 효과와 설정을 유지하므로 같은 원본의 일부 구간에만 리버브를 적용할 수 있습니다.
- 공간 크기, 거리, 프리 딜레이, 잔향 시간, 톤, Dry/Wet 등 주요 값을 속성 패널에서 조절할 수 있습니다.
- 같은 효과를 다시 열어도 편집기가 중복 생성되지 않으며, 효과 카드를 통해 활성화와 제거 상태를 확인할 수 있습니다.

## 끊기지 않는 실시간 미리듣기

- 재생 중 리버브와 음량 값을 바꾸면 현재 위치에서 즉시 반영됩니다.
- 클립 이동이나 분할처럼 음원 배치가 바뀌는 작업은 백그라운드에서 준비한 뒤 짧게 교차 전환합니다.
- 효과 변경 때문에 전체 곡을 다시 렌더링하지 않아 긴 곡에서도 조작 지연을 줄였습니다.
- 내보내기에는 같은 설정을 고품질 오프라인 처리로 적용하고 리버브 꼬리까지 보존합니다.

## 업데이트와 런타임 안정성

- 0.2.x 설치본에서 0.3.x 오디오 엔진으로 넘어갈 때 발생할 수 있던 런타임 교체 실패를 수정했습니다.
- 정밀 분리 구성요소를 두 가지 지원 위치에서 모두 감지해 정상 설치를 누락하지 않습니다.
- 완료된 업데이트 다운로드와 임시 파일을 안전하게 정리하고, 패치노트를 앱에서 바로 열 수 있습니다.
- 다운로드와 설치가 필요한 항목을 구분해 앱 내부에서 처리 가능한 단계와 재시작이 필요한 단계를 명확히 표시합니다.

## UI 및 품질 개선

- 작업곡 버튼이 나타날 때 라이브러리 파형이 밀리지 않도록 행 레이아웃을 고정했습니다.
- 첫 실행 저장 위치 선택 문구와 모드를 정리하고 한국어·영어 표시 누락을 보완했습니다.
- 기존 스튜디오 프로젝트는 효과가 없는 상태로 그대로 열리며, 새 효과 데이터도 이전 버전이 읽을 수 있는 프로젝트 구조를 해치지 않습니다.

## 업데이트 전 확인

- 곡, 모델, 스튜디오 프로젝트, 출력 파일과 사용자가 선택한 저장 위치는 업데이트 후에도 유지됩니다.
- 오디오 엔진 업데이트가 필요한 설치본은 앱 업데이트 후 안내에 따라 한 번 더 구성요소 설치가 진행될 수 있습니다.
- 정식 설치 파일과 자동 업데이트 구성요소는 [GitHub Releases](https://github.com/groun519/JJZ-Audio/releases)에서 제공합니다.
