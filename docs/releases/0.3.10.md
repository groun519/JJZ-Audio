# JJZero Audio 0.3.10

> 여러 클립을 한 번에 다루는 스튜디오 편집과 프로젝트 복구 흐름을 강화하고, RVC 학습과 애플리케이션 업데이트의 실패 가능성을 줄인 안정화 업데이트입니다.

0.3.10은 스튜디오 다중 편집, 프로젝트 이력 복구, RVC 학습 사전 검증과 완료 판정, Google Drive 모델 가져오기 및 앱 전용 업데이트 검증을 중심으로 개선합니다. 기존 곡, 모델, 학습 재료, 체크포인트, 스튜디오 프로젝트와 출력 파일은 그대로 유지됩니다.

![스튜디오 다중 클립 선택과 일괄 조정](https://raw.githubusercontent.com/groun519/JJZ-Audio/v0.3.10/docs/assets/releases/0.3.10/studio-multi-clip-editing.png)

## 스튜디오 다중 편집

- 빈 영역을 드래그하거나 `Shift`를 사용해 여러 클립을 함께 선택할 수 있습니다.
- 선택한 클립을 같은 간격으로 이동하고 한 번에 제거할 수 있습니다.
- 우측 속성 패널에서 선택한 모든 클립의 음량과 피치를 현재 값 기준으로 조절하고 음소거 상태를 함께 변경할 수 있습니다.
- 여러 클립 이동에도 자석 맞춤과 겹침 방지 규칙을 동일하게 적용합니다.

## 프로젝트 이력과 복구

- 스튜디오 프로젝트의 저장 이력을 별도로 관리하고 원하는 정상 시점으로 복구할 수 있습니다.
- 선택한 클립, 타임라인 확대와 스크롤 위치를 작업곡별로 보존합니다.
- 현재 파일이 손상됐거나 연결된 음원이 사라진 경우 복구 결과와 누락된 항목을 명확히 안내합니다.
- 곡 데이터를 제거할 때 프로젝트 이력과 내부 상태 파일도 함께 정리하되 일반 출력 목록에는 노출하지 않습니다.

## RVC 학습 안정성

- 학습을 시작하기 전에 선택된 RVC 런타임의 필수 파일과 GPU 가속 상태를 확인합니다.
- GPU용 런타임이 설치됐지만 실제 가속을 사용할 수 없는 경우 CPU로 조용히 진행하지 않고 복구 가능한 오류로 안내합니다.
- 최종 체크포인트 저장과 학습 완료 문구를 감지해, 완료 직후 발생한 작업자 종료 신호를 실패로 잘못 처리하지 않습니다.
- 표준 출력과 오류 출력을 함께 수집해 런타임·학습 실패 로그의 원인 정보를 보강했습니다.
- 학습 중에는 모델 추가와 새로고침을 잠가 충돌하는 모델 라이브러리 작업을 막습니다.

## 모델과 공유

- 공개 Google Drive 모델 링크를 가져오기 전에 링크와 파일 ID를 검증합니다.
- 잘못된 링크는 다운로드를 시작하기 전에 이유를 표시합니다.
- 공유 진행 상태와 원격 파일 제거 동작을 정리했습니다.

## 업데이트 안정성

- 앱 전용 업데이트 매니페스트가 기존 AI·GPU 런타임의 검증된 불변 URL을 그대로 보존합니다.
- 게시 전에 재사용하는 모든 원격 런타임 파일의 이름과 크기를 GitHub Release에서 다시 확인합니다.
- 0.3.10은 기존 AI·GPU 런타임을 재사용하므로 정상 구성된 PC에서는 대용량 런타임을 다시 받을 필요가 없습니다.

## 보컬 정리 기능

- 보컬 정리 작업 공간은 아직 완성된 기능이 아니므로 0.3.10 릴리스 화면에서는 접근할 수 없게 잠갔습니다.
- 내부 구현은 정식 검수와 사용 흐름이 완성될 때까지 실험 상태로 유지합니다.

## 업데이트 안내

- 설치 프로그램은 기존 데이터 위치와 사용자 자료를 유지합니다.
- 학습 중인 작업이 있다면 종료한 뒤 업데이트하는 것을 권장합니다.
- 코드 서명 인증서가 아직 구성되지 않아 Windows에서 게시자 경고가 표시될 수 있습니다.
