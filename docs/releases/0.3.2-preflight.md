# JJZero Audio 0.3.2 사전 마감표

> 이 문서는 0.3.2 개발 중 확정된 범위와 최종 릴리스 순서를 관리합니다. 사용자용 패치노트가 아닙니다.

## 현재 기준

- 릴리스 후보 버전: `0.3.2`
- 기준 릴리스 커밋: `374ba63` (`Release 0.3.1`)
- 기능 범위 커밋: `1666d9d` (`Production Workflow 01`)
- 앱 버전, Windows 버전 정보, README를 `0.3.2`로 확정했습니다.
- 진행 중인 로컬 변경은 테스트와 커밋이 끝난 뒤에만 확정 범위로 이동합니다.

- `2026-08-13`: Python 컴파일 검사 통과
- `2026-08-13`: 전체 자동 테스트 `1,025개` 통과

## 기능 동결 전 정리

- 병렬 작업을 모두 끝내고 기능별 커밋 경계를 확정합니다.
- 0.3.1 이후 커밋을 사용자 기능, 수정, 내부 품질 작업으로 다시 분류합니다.
- 미추적 소스와 테스트 파일이 누락되지 않았는지 확인합니다.
- 생성 파일, 로컬 미디어, 런타임, 캐시가 Git 변경에 섞이지 않았는지 확인합니다.
- 앱 버전이나 런타임 버전을 먼저 올리지 않습니다.

## 최종 검증

1. 전체 테스트를 통과시킵니다.
2. 앱 시작, 페이지 전환, 종료 시 임시 창이나 CMD가 나타나지 않는지 확인합니다.
3. 기존 0.3.1 라이브러리, 모델, 작업곡, Studio 세션을 그대로 불러옵니다.
4. 라이브러리 재생, 작업곡 전환, 분리, 변환, Studio 재생, 오디오 및 영상 내보내기를 점검합니다.
5. Studio 타임라인 편집, 사운드 제거, 미디어 배치와 저장 후 복원을 확인합니다.
6. NVIDIA, AMD, CPU 환경에서 진단 결과와 지원 경로가 실제 동작과 일치하는지 확인합니다.
7. 업데이트 후 사용자 데이터와 외부 연결 모델이 유지되는지 확인합니다.

## 버전 및 문서 마감

1. `CHANGELOG.md`의 `Unreleased`를 최종 검수합니다.
2. 사용자용 `docs/releases/0.3.2.md`를 작성합니다.
3. `src/jang_app/version.py`를 `0.3.2`로 변경합니다.
4. Windows 버전 정보를 다시 생성합니다.
5. README의 현재 배포 버전과 패치노트 링크를 `0.3.2`로 변경합니다.
6. 전체 테스트를 다시 실행하고 릴리스 커밋을 만듭니다.
