# JJZero Audio 0.3.10 사전 마감표

> 이 문서는 0.3.10 릴리스의 로컬 검증 결과를 기록합니다. 사용자용 변경 사항은 [0.3.10 패치노트](0.3.10.md)를 확인합니다.

## 범위

- 기준 공개 버전: `0.3.9` (`e5a4407`)
- 목표 버전: `0.3.10`
- 릴리스 소스: `33f9152`
- 애플리케이션 전용 업데이트: 검증된 `v0.3.0` AI·GPU 런타임 구성요소 재사용
- 주요 범위: 스튜디오 다중 클립 편집과 프로젝트 기록, RVC 학습 안정성, 모델·공유 관리, 업데이트 신뢰성
- 보컬 정리 기능은 완성 전 기능으로 판정하여 0.3.10 배포 UI에서 접근할 수 없도록 잠금

## 완료된 검증

- 전체 Python 테스트 1,386개 통과
- `src`, `tests`, `scripts` Python 컴파일 검증 통과
- `git diff --check` 통과
- 배포 폴더 구성과 동결 앱 빌드 검사 통과
- 릴리스 준비 및 구성요소 매니페스트 검증 통과
- README, 패치노트와 변경 기록 UTF-8 검사 통과
- 실제 Windows 렌더러로 촬영한 패치노트 이미지 존재와 경로 확인
- 애플리케이션 구성요소 이름, 크기와 SHA-256 일치 확인
- AI·GPU 런타임 16개 자산이 불변 `v0.3.0` URL을 사용하는지 확인
- `0.3.9 → 0.3.10` 실제 업데이트 설치와 제품 버전 확인
- 관리 저장소 마이그레이션과 사용자 라이브러리·모델·설정·출력 파일 보존 확인
- 제거 후 애플리케이션·Runtime·Cache 정리와 사용자 Data·Output 보존 확인
- 보컬 정리 메뉴 비노출과 직접 탐색 요청 차단 테스트 통과
