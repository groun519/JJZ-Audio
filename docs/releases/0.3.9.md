# JJZero Audio 0.3.9

> 변환에 맞는 피치를 더 쉽게 판단하고, 모델의 안정 음역과 결과 타임라인을 더 정확하게 확인할 수 있도록 제작 흐름을 다듬은 업데이트입니다.

0.3.9는 곡과 모델의 음역 정보를 연결한 피치 추천, 스튜디오 하드 튠, 모델 정밀 평가 결과의 시각화와 영상 공유용 내보내기를 중심으로 개선합니다. 기존 곡, 모델, 학습 재료, 체크포인트, 스튜디오 프로젝트와 출력 파일은 그대로 유지됩니다.

![모델의 안정 음역과 음별 정밀 평가](https://raw.githubusercontent.com/groun519/JJZ-Audio/v0.3.9/docs/assets/releases/0.3.9/model-precision-evaluation.png)

## 변환 피치 가이드

- 선택한 보컬의 실제 음역과 모델이 안정적으로 처리하는 음역을 함께 분석해 권장 피치를 표시합니다.
- 권장 범위와 선택한 피치의 차이를 한눈에 비교하고, 큰 이동이 필요한 경우 품질 저하 가능성을 미리 안내합니다.
- 분석 결과를 캐시해 같은 음원과 모델을 다시 선택했을 때 불필요한 계산을 줄입니다.

## 모델 정밀 평가

- 동일한 기준 보컬을 C2부터 C6까지 반음 단위로 평가해 모델의 음별 변환 안정성을 확인합니다.
- 안정 음역과 확장 가능 음역을 구분하고, 음별 점수와 연속된 안정 구간을 그래프로 표시합니다.
- 모델 자체의 안정 음역과 특정 곡의 권장 피치가 다른 정보임을 화면에서 명확히 구분합니다.
- 평가가 진행되는 동안 다른 화면으로 이동해도 작업이 계속되며 진행 상태와 완료 결과를 다시 확인할 수 있습니다.

## 스튜디오 하드 튠

- 스튜디오 FX에 하드 튠을 추가해 키, 스케일, 보정 강도, 반응 속도와 비브라토 보존량을 조절할 수 있습니다.
- 자연스러운 보정부터 강한 합성 보컬까지 빠르게 시작할 수 있는 프리셋을 제공합니다.
- 재생 중 미리듣기와 최종 오디오 내보내기에 같은 설정을 적용합니다.

## 결과 타임라인

- 분리·변환 결과를 공통 시간 눈금과 정렬된 파형 트랙으로 표시합니다.
- 원본 보컬, 반주와 변환 보컬의 같은 시점을 더 쉽게 비교하고 재생 위치를 정확하게 확인할 수 있습니다.
- 변환 화면에서는 사용할 결과를 명시적으로 선택하도록 해 여러 변환본이 있을 때 의도하지 않은 파일이 재생되는 문제를 줄였습니다.

## 공유용 영상 내보내기

- Discord 등 파일 크기 제한이 있는 공유 환경을 위한 10MB 영상 프리셋을 추가했습니다.
- 영상의 대표 구간을 비교해 콘텐츠에 맞는 해상도를 선택하고, 2-pass 인코딩으로 제한 용량 안에서 화질을 최대한 유지합니다.
- 영상 길이가 제한 용량에서 실사용 가능한 품질을 유지하기 어려운 경우 무리하게 낮은 품질로 출력하지 않고 이유를 안내합니다.

## 결과 관리

- 내보낸 오디오와 영상 행에서 불필요한 결과 파일을 바로 제거할 수 있습니다.
- 행 동작 버튼의 규격과 호버 표시를 정리해 이름 변경, 위치 열기, 공유와 삭제를 구분하기 쉽게 했습니다.

## 저장과 학습 안정성

- 스튜디오 편집 내용이 저장 중 오류로 사라지지 않도록 실패한 자동 저장을 보존하고 다시 시도합니다.
- 서로 다른 편집 상태를 기록해 현재 세션 파일이 손상된 경우 가장 최근의 정상 기록으로 복구합니다.
- RVC 학습이 최종 체크포인트를 정상 저장한 뒤에도 종료되지 않는 경우 완료 결과를 보존한 채 남은 학습 프로세스를 안전하게 정리합니다.

## 업데이트 안내

- 0.3.9는 애플리케이션 전용 업데이트로 준비 중이며 기존 0.3.8 AI 런타임 구성요소를 재사용합니다.
- 정상 구성된 PC에서는 대용량 AI 런타임을 다시 받을 필요가 없습니다.
- 설치 프로그램은 기존 데이터 위치와 사용자 자료를 유지합니다.
