# RVC 결과 품질 연구

- 상태: 조사 중
- 시작일: 2026-08-13
- 범위: 동일한 분리 보컬과 동일한 RVC 모델을 사용했을 때 변환 결과의 품질을 높이는 방법
- 최종 판단 기준: 발음 보존, 음색 유사도, 음정 안정성, 보컬 누락, 금속성·찢어짐·잡음, 최종 믹스 적합성

## 연구 원칙

- 보컬 분리 품질은 입력 조건으로 기록하되 이 연구의 독립 변수로 섞지 않는다.
- 한 번에 하나의 변수를 바꿔 원인을 구분한다.
- 자동 지표는 후보를 거르는 용도로만 사용하고 최종 판단은 블라인드 청취로 한다.
- 모델마다 최적값이 다를 수 있으므로 하나의 전역값을 성급히 확정하지 않는다.

## 문제 1: 고정된 RVC 추론 파라미터

### 현재 상태

현재 변환 CLI는 곡과 모델에 관계없이 다음 값을 사용한다.

| 항목 | 현재 값 | 위험 |
| --- | ---: | --- |
| Index rate | 1.0 | 학습 데이터의 음색을 강하게 반영하지만 잡음, 거친 발음과 검색 오류도 함께 증폭할 수 있음 |
| RMS mix rate | 0.0 | 변환 결과의 음량 윤곽을 원본 입력에 전부 맞추며 다른 선택지를 비교할 수 없음 |
| Protect | 0.33 | 일반적인 기본값이지만 보컬과 모델 특성에 따른 조절이 불가능함 |
| F0 method | RMVPE | 좋은 기본값이지만 오류 구간을 감지하거나 다른 방식으로 재처리할 수 없음 |

최신 공식 RVC 구현의 기본값은 `index_rate=0.75`, `rms_mix_rate=0.25`,
`protect=0.33`이다. 공식 문서도 지나치게 높은 Index rate가 아티팩트를
만들 수 있으며, 학습 데이터 품질이 낮을 때 높은 값이 결과 품질을 낮출 수
있다고 설명한다.

### 핵심 가설

`index_rate=1.0` 고정이 일부 모델에서 금속성, 발음 뭉개짐, 잡음 복제와
불안정한 고음을 증가시키고 있다. 최적값은 전역 기본값 하나가 아니라
RVC 모델과 입력곡 조합에 따라 달라질 가능성이 높다.

### 첫 검증

같은 입력 구간, 모델, 피치와 RMVPE 결과를 유지하고 Index rate만 바꾼다.

- 0.00: 인덱스 미사용 기준본
- 0.50: 원본 특징 보존 중심
- 0.65: 중간 후보
- 0.75: 최신 공식 기본값
- 1.00: 현재 JJZero Audio 결과

첫 비교에서 확인할 항목은 다음과 같다.

- 목표 음색이 약해지거나 강해지는 정도
- 자음과 가사의 선명도
- 숨소리와 무성음의 찢어짐
- 지속음과 고음에서 발생하는 금속성
- 학습 데이터의 잡음 또는 잔향 복제

Index rate 후보가 정리된 뒤에만 RMS mix rate와 Protect를 각각 별도로 비교한다.

### 목표 결과

- 추론 파라미터를 변환 엔진까지 전달할 수 있다.
- 안전한 기본 프리셋과 고급 조절값을 분리한다.
- 모델별 권장값을 저장할 수 있다.
- 선택한 곡의 짧은 구간으로 후보를 빠르게 생성하고 비교할 수 있다.
- 실제 변환에 사용한 값을 결과 메타데이터와 진단 로그에 남긴다.

### 상태

- 원인 후보 확인
- 추론값 전달 및 저장 구현 완료
- 변환 화면 프리셋 및 세부 조절 구현 완료
- 변환 결과 메타데이터와 진단 로그 기록 완료
- 청취 벤치마크 전

### 구현된 시작 프리셋

| 프리셋 | Index | Filter | RMS | Protect | 목적 |
| --- | ---: | ---: | ---: | ---: | --- |
| 균형 | 0.75 | 3 | 0.25 | 0.33 | 공식 기준값으로 안정적인 첫 변환 |
| 음색 | 0.90 | 3 | 0.25 | 0.33 | 인덱스 음색을 더 강하게 반영 |
| 디테일 | 0.55 | 3 | 0.25 | 0.20 | 원본 자음과 호흡을 더 보존 |

프리셋은 최종 권장값이 아니라 청취 비교를 시작하기 위한 후보군이다.

### 다음 청취 순서

1. `오존` 문제 구간과 `pq-a` 모델을 고정한다.
2. 균형 프리셋에서 Index만 `0.00`, `0.50`, `0.65`, `0.75`, `1.00`으로 비교한다.
3. 상위 두 Index 후보에서 Protect만 `0.20`, `0.33`, `0.50`으로 비교한다.
4. 상위 후보에서 RMS만 `0.00`, `0.25`, `0.50`, `1.00`으로 비교한다.
5. 최종 후보를 전체 곡과 다른 RVC 모델에 적용해 범용성을 확인한다.
