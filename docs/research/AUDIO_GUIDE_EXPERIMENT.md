# 분리 보컬 기반 가이드 생성 연구 종료 기록

## 결론

`분리 보컬 -> 자동 가이드 보컬 -> RVC` 경로는 제품 후보에서 제외한다.

공개 모델 조합으로는 임의의 곡에서 원곡과 같은 가사, 음정, 발음 위치, 프레이징을
자동으로 재현하지 못했다. 가사를 사용자가 확인해도 합성기가 자음 시작점, 모음 길이,
멜리스마와 호흡을 다시 해석하므로 원곡과 차이가 남았다. 곡마다 수동으로 음소 위치를
교정해야 하는 방식은 JJZero Audio의 자동 작업 흐름에 적합하지 않다.

## 검증한 경로

| 경로 | 결과 |
| --- | --- |
| Seed-VC 기반 재생성 | 분리 누출과 잔향까지 다시 음성화해 제외 |
| YingMusic-Singer-Plus | 원곡 선율과 프레이징을 유지하지 못해 제외 |
| GAME + SoulX-Singer | 대략적인 음정은 유지했지만 가사 정렬과 발음 위치가 불안정해 제외 |
| 강제 가사 정렬 + 연속 F0 | 오차를 줄였으나 수동 보정 없이 동일 퍼포먼스를 재현하지 못함 |

## 기술적 판단

- 정확한 가사와 F0만으로는 동일한 가창을 결정할 수 없다.
- 분리 과정에서 사라진 음소와 표현 정보는 입력만으로 완전히 복원할 수 없다.
- 일반 가창 합성 모델은 원곡을 복원하지 않고 새로운 퍼포먼스를 생성한다.
- 자동 정렬 결과를 수동 편집해야 품질이 나오는 구조는 기본 기능으로 채택하지 않는다.

깨끗한 가이드가 다시 필요하다면 범용 합성기를 연결하지 않고, 손상된 분리 보컬과
정확한 가사를 입력받아 같은 퍼포먼스의 깨끗한 보컬을 출력하도록 학습한 전용 복원
모델이 필요하다. 이는 별도의 장기 AI 모델 연구 과제로 취급한다.

## 제품 방향

당분간 다음 흐름을 유지한다.

`원곡 -> 보컬 분리 개선 -> 직접 RVC -> 믹스`

다음 품질 연구는 Kim 계열의 높은 보컬 보존율과 Bleedless 또는 HTDemucs의 낮은 반주
누출을 결합하되, 단순 평균하지 않고 기준본에서 누락된 보컬 성분만 복구하는 방식에
집중한다. 디리버브는 보컬 손실을 막기 위해 선택적이고 보수적인 후처리로 검증한다.
